# 🍽️ Restaurant App - Itsuki

Backend de una aplicación móvil para la gestión de pedidos en un restaurante, desarrollado con **Spring Boot** y **Java**. Proporciona la API REST utilizada por la aplicación para consultar el menú, administrar el carrito de compras y procesar los pedidos.

## Funcionalidades

- Consultar el menú de comidas.
- Gestionar el carrito de compras.
- Actualizar la cantidad de productos.
- Eliminar productos del carrito.
- Procesar pedidos.
- Conexión con base de datos mediante Spring Boot.

## Tecnologías utilizadas

- Java
- Spring Boot
- Maven
- MySQL
- JPA / Hibernate

## Base de datos

El repositorio incluye el script SQL necesario para crear la base de datos y sus tablas.
